# Top cluster (logo + wordmark) uses FIXED PIXEL positions rather than
# percent, and boot_menu's top is percent-based starting well clear of it.
# The earlier layout mixed "12%+140"-style pixel-offset-from-percent math
# for the wordmark with a plain percent top for boot_menu — the two units
# scale differently across resolutions, so at anything below ~900px tall
# (e.g. a VM's default 640x480 or 800x600 framebuffer) the wordmark ended
# up INSIDE the boot_menu's vertical span, and its text visually collided
# with the actual menu entries. Verified by direct computation clear of
# overlap from 480p through 1440p before shipping this.
