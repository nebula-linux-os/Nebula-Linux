🎨 Material You Theming

🚀 Plymouth Splash (new)

Boot animation with an orbiting singularity replaces the console text scroll. Silent boot with quiet splash is wired in automatically on install.

🐛 Native Bug Reporter (new)

nebula bugreport --open gathers OS, kernel, GPU, DMS versions and failed services, then opens a pre-filled GitHub issue in your browser.

⏪ Snapshots & Rollback

Installs on btrfs with snapper. Every update takes automatic before/after snapshots, and any older state is bootable straight from the GRUB menu. A rolling release you can't really break.

🧭 Nebula Welcome

First boot greets you with a native onboarding app: install to disk, learn the niri workflow, enable Flathub, and grab app bundles for development, gaming or creative work.

⚡ The nebula CLI

One command for system care: nebula update, nebula snapshots, nebula rollback, nebula drivers (with one-shot NVIDIA install) and nebula doctor.

🔒 Dank Greeter & Lock

Installed systems log in through the DankMaterialShell graphical greeter, and the lock screen carries your wallpaper, Material colors and avatar. Branded from power-on to desktop.

🖥️ VM-Friendly

Guest tools for QEMU/KVM, VirtualBox and VMware start automatically when a hypervisor is detected — clipboard sharing and display resize just work. Great for trying before installing.

Hardware Requirements

⚠️ Nebula Linux requires UEFI boot mode. Legacy BIOS boot is not supported in Beta 1.0 (a confirmed GRUB bug with our btrfs + snapshot-safe partition layout). The installer will warn you if it detects BIOS mode — enable UEFI in your firmware/VM settings first.

Minimum Specs

  • CPU: 64-bit Dual Core (2 GHz)
  • RAM: 4 GB
  • Storage: 25 GB free space
  • GPU: VGA capable of 1024x768

Recommended Specs

  • CPU: 64-bit Quad Core (3 GHz)
  • RAM: 8 GB
  • Storage: 50+ GB SSD
  • GPU: Any modern AMD/Intel/NVIDIA

Frequently Asked Questions

What is Nebula Linux based on?
Nebula Linux is built on Arch Linux with the Dank Linux desktop — DankMaterialShell running on the niri scrollable-tiling Wayland compositor, with a full Material You theme generated live from your wallpaper.
How do I install it?
Download the `.iso` file and use a tool like Rufus (Windows) or BalenaEtcher (Mac/Linux) to flash it to a USB drive. Boot your computer from the USB drive, and follow the branded Calamares installer. Nebula Linux requires UEFI boot mode — enable UEFI in your firmware/VM settings before installing (the installer warns you if it detects legacy BIOS mode).
Is this ready for daily use?
Nebula Linux is currently in an Alpha stage of development. While it is fully functional and incredibly fast, you may encounter bugs. We recommend testing it in a Virtual Machine (like VirtualBox) or on a secondary computer first.
