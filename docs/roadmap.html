🌌 Beta 1.0 (New!)

August 1, 2026

Four curated wallpaper themes bundled by default (Cosmic Blue, Stellar Ember, Aurora Light, Void Green) with an in-app picker on the Nebula Welcome screen, defaulting to Auto (wallpaper-derived) color mode. New nebula wallpaper and nebula bugreport subcommands. Plymouth animated boot splash (orbiting singularity) with automatic quiet splash wiring. Full branded GRUB theme for installed systems. Dedicated ext4 /boot partition (off btrfs) for reliable booting. Fixed graphical login screen crash. Weekly auto-built ISOs via GitHub Actions on a Monday cron.

⚠️ Known limitation: legacy BIOS boot is not supported this release — a confirmed grub-install bug in this GRUB build. UEFI is required. The installer detects and warns on BIOS-mode systems.

🔄 Arch · Dank Edition — Alpha 2

July 16, 2026

DankMaterialShell refreshed to 1.5.1. Highlights: automatic Xray blur behind windows on niri/Hyprland, greeter & lockscreen customization panels, lockscreen screen filter, new Notepad app with IPC file handling, hover popout & launcher in all bar modes, per-display workspace appearance, horizontal battery pill, mpris player exclusions, and matugen palette preview. Full package refresh (496 MB of Arch updates) alongside the same Nebula stack.

✨ Arch · Dank Edition Released

July 5, 2026

A whole new edition built on Arch Linux with DankMaterialShell on the niri compositor. Ships a branded Calamares installer, btrfs snapshots with GRUB rollback (snapper + snap-pac + grub-btrfs), the Nebula Welcome onboarding app, the nebula control-center CLI, a Material You theme generated from your wallpaper, the Dank graphical greeter, VM guest-tools auto-setup and zram. Verified working in VirtualBox.

✅ One Distro, Two Editions

July 5, 2026

The project was restructured: the new Arch · Dank Edition now lives on the main branch, the original Debian + KDE Plasma 6 edition continues on the Debian_Edition branch, and the website presents both.

✅ Alpha v1.0 Polish & Theming

June 25, 2026

Implemented automatic Global Dark Mode for all new users, pre-installed the Plasma Discover App Store with native Flatpak support, and finalized the system "Alpha v1.0" branding.

✅ Calamares & Wayland Integration

June 24, 2026

Successfully integrated the Calamares graphical installer with KDE Plasma 6 Wayland. Fixed the fatal Qt6/Wayland root crashing bugs and rebuilt the YAML installer branding.

✅ The Birth of Nebula Linux

June 23, 2026

The core Debian Trixie (Debian 13) Live OS was successfully bootstrapped. We set up the initial custom KDE desktop and built the very first bootable ISO image.
